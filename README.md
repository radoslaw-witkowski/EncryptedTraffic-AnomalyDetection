# Anomaly Detection in Encrypted Network Traffic (Master Thesis)

This repository contains the ongoing work for my MSc thesis on detecting anomalies in encrypted network traffic using self-supervised learning techniques.

## Goals
- Analyse encrypted network flows
- Prepare datasets for training
- Experiment with self-supervised learning approaches
- Build a prototype anomaly detection model

## Technologies
- Python
- Machine Learning
- Self-Supervised Learning
- Network traffic analysis

## Status
Work in progress – early research and data preparation phase.
